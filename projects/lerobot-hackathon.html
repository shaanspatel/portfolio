Overview

This project centered on getting a robot learning stack working on physical hardware under hackathon time pressure. Problem / Motivation

In a robotics hackathon, the challenge is not only model code; it is making hardware, task setup, data collection, and evaluation reliable enough to demonstrate. This project belongs in the portfolio because the software mattered where it supported a physical robot workflow.

Engineering Constraints

The project was constrained by limited event time, available robot hardware, camera/workspace setup, task repeatability, data quality, and reliability of the demo environment. Exact hardware names, dataset sizes, training time, and scoring details should be added from team records before publication.

Design Approach

The approach was to scope the task around a repeatable physical setup, then connect the LeRobot workflow to the available robot arms and observation stream. Keeping the task setup simple made it easier to iterate on demonstrations and diagnose whether failures came from hardware, data, policy behavior, or the environment.
